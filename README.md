# 🌕 月相測量師 (Moon Surveyor Pro)

> 專為風景攝影師、天文愛好者與戶外勘景設計的手機端互動式 Web App（PWA）。  
> 整合**中華民國交通部中央氣象署「月出月沒時刻」官方開放資料（A-B0063-001 / ID: 75381）**與高精度天體力學演算法，實現如同《太陽測量師》（Sun Surveyor）的專業追蹤體驗。

---

## 📸 核心特色與四大專業視圖

### 1. 🗺️ 互動地圖模式 (Interactive Map View)
* **天文光線動態發射**：以觀測點為中心，即時投射四條導引光芒：
  * 🌕 **金黃射線**：當日官方**月出方位角**（標註升起時刻與角度）
  * 🌘 **橙紅射線**：當日官方**月沒方位角**（標註落下時刻與角度）
  * 🌙 **青銀光束**：當前時刻**月球即時方位角與仰角**（隨時光軸流暢旋轉）
  * ☀️ **熾暖琥珀射線**：當前時刻**太陽即時方位角與仰角**
* **無 API Key 免費高畫質圖資**：
  * **暗夜天文底圖（預設）**：採用 ESRI World Dark Gray Canvas，暗黑低光害背景，專為夜間觀星打造。
  * **衛星空照圖**：採用 ESRI World Imagery 高解析實景地貌。
  * **地形街道圖**：採用 ESRI World Street Map 道路建築圖資。
* **自由釘選與測距**：在地圖任意處點擊放置釘選點，或拖曳觀測者圖釘，隨附距離半徑參考圓。

### 2. 🧭 3D/2D 天文天球羅盤 (Celestial Compass View)
* **手機電子指南針連動**：支援行動裝置陀螺儀（`DeviceOrientationEvent`），轉動手機時羅盤依據真實磁北方向即時轉向。
* **天頂仰角環**：0°（地平線）、30°、60°、90°（天頂）同心圓刻度。
* **整日運行弧線**：立體呈現太陽與月亮今日 24 小時在空中的天球運行弧線與即時位置發光球體。

### 3. 📷 擴增實境透視 (AR Camera View)
* **手機後鏡頭實景疊加**：啟動手機相機（`getUserMedia`），將空中虛擬地平線、仰角階梯、以及月亮在空中的軌跡弧線直接投射到相機畫面中！
* **勘景神兵**：站在拍攝現場舉起手機，立刻得知幾點幾分月亮會升至前方特定建築或山峰。
* **模擬背景支援**：在未取得相機授權或電腦端測試時，自動啟用擬真山嶺星空背景。

### 4. 📊 星曆表與氣象署官方對照 (Ephemeris & CWA Verification)
* **3D 月相球體 Shader**：即時 Canvas 計算月相終結線陰影、照亮比例 %、月齡天數、地月距離與視直徑。
* **中央氣象署 75381 官方資料對照卡**：呈現 2025–2027 三年官方月出、過中天仰角、月沒時刻與方位角基準。
* **攝影光影黃金時段**：自動計算晨間/傍晚黃金時段（Golden Hour）與藍調時段（Blue Hour）。
* **月相穿梭**：提供「🌕 下次滿月」與「🌑 下次新月」一鍵跳轉。

### 5. ⏱️ 24 小時時光機滑桿 (Timeline Slider Dock)
* 底部常駐連續滑桿（00:00 ～ 23:59），滑動時以 **60fps 毫秒級**同步驅動所有地圖、羅盤、AR 與仰角數據。
* 軌道動態標註日出、日落、月出、月沒關鍵時間點。
* 提供「▶ 播放推演」（120x 縮時模擬全天光影變化）與「⏮ 回到現在時間」。

### 6. 📍 地點查詢與 GPS 定位
* **📍 定位目前地點**：一鍵呼叫瀏覽器高精度 GPS 定位。
* **臺灣 22 縣市代表中心**：臺北市、新北市、臺中市、高雄市、花蓮縣、澎湖、金門、連江等。
* **10 大熱門攝影觀星聖地**：合歡山武嶺、象山六巨石（101懸月）、阿里山祝山、日月潭朝霧碼頭、墾丁龍磐公園、台東三仙台、鼻頭角燈塔等。
* **關鍵字搜尋**：整合 OpenStreetMap Nominatim 臺灣即時地理編碼搜尋。

## 🔄 每年自動更新資料機制

1. **客戶端背景無感更新 (`src/utils/dataUpdater.js`)**：
   * 預先封裝 2025–2027 三年官方完整資料（高壓縮僅約 1MB，Gzip 後 268KB，離線秒開）。
   * App 啟動時自動比對本地快取時間；若跨越新年份（如進入 2028 年）或已超過 30 天未檢查，會在背景自動向氣象署開放資料 API 請求最新發布資料，並靜默更新至 IndexedDB 快取。
2. **高精度天文力學引擎保底**：
   * 即使在完全無收訊的深山或離島，內建天文引擎仍可推算至未來任意年份與秒數的天體座標，永不中斷。
3. **自動化批次更新腳本 (`scripts/update_cwa_data.py`)**：
   * 支援以 CLI 或排程（Cron / CI）執行 `npm run update-data`，自動抓取中央氣象署最新發布的完整年度資料。

## 🛠️ 技術堆疊

* **前端框架**：Vite 8 + 原生 JavaScript（Vanilla ES Modules），極致輕量與原生流暢度。
* **地圖圖資**：Leaflet + ESRI World Dark Gray / Satellite / Street Basemaps（免 API Key）。
* **天體曆算**：SunCalc + 天球幾何坐標轉換演算法。
* **行動端適配**：HTML5 Canvas、DeviceOrientation API、MediaDevices（WebRTC）、PWA（Service Worker + Web App Manifest）。

## 🚀 本地開發與啟動指南

### 1. 安裝相依套件
```bash
npm install
```

### 2. 啟動開發伺服器
```bash
npm run dev
```
啟動後於瀏覽器開啟 `http://localhost:5173/`。

### 3. 手機連線測試
若手機與電腦處於相同 Wi-Fi 網路，手機瀏覽器直接輸入終端機顯示的區域網路 IP（例如 `http://192.168.x.x:5173/`），即可體驗 **AR 相機實景** 與 **實體手機指南針旋轉**。

### 4. 更新中央氣象署最新年度資料
```bash
npm run update-data
```

### 5. 一鍵啟用 GitHub Pages (手機專屬線上網址)

本專案已內建 GitHub Actions 自動化部署工作流（`.github/workflows/deploy.yml`）：
1. 前往 GitHub 儲存庫頁面：[https://github.com/taichi16/moon_surveyor](https://github.com/taichi16/moon_surveyor)
2. 點選上方分頁 **「Settings」** ➔ 左側選單 **「Pages」**。
3. 在 **「Build and deployment」>「Source」** 下拉選單中，切換為 **`GitHub Actions`**。
4. 儲存後 GitHub 就會自動編譯並部署，約 1 分鐘後即可在手機透過專屬 HTTPS 網址連線使用：
   **`https://taichi16.github.io/moon_surveyor/`**
